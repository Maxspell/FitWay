# FitWay Social Generator

Генерирует готовый к публикации мультиплатформенный пакет контента для **FitWay** (`https://fitway.best`) с фокусом на **Pinterest-first SEO** и привлечение органического **Tier-1 (US/UK/CA)** трафика на статьи, тренировки и калькуляторы сайта.

**Справочники этого скилла (читай перед генерацией):**
- **Реестр уже опубликованных пинов (дедупликация!)** — `references/existing-pins.md`
- **Pinterest SEO, 5 живых досок и шаблоны промптов 2:3** — `references/pinterest-seo-guide.md`
- **Плейбуки YouTube Shorts (+ Reels/TikTok), X и Reddit** — `references/platform-playbooks.md`

**Связанные скиллы и реестры проекта:**
- **Анти-AI фильтр (обязательно)** — `.agents/skills/humanizer/SKILL.md`
- **Проверка валидных URL статей** — `.agents/skills/fitway-blog-post-generator/references/existing-posts.md`
- **Проверка валидных URL тренировок** — `.agents/skills/fitway-workout-generator/references/existing-workouts.md`
- **Карта калькуляторов `/tools/*` и категорий** — `.agents/skills/fitway-blog-post-generator/references/internal-links.md`
- **Фреймворки видео-хуков и лимиты платформ** — `.agents/skills/social/references/short-form-video.md` и `.agents/skills/social/references/platform-limits.md`
- **Живые ключи GSC** — `brain/data/gsc-latest.json`

## Приоритет платформ (FitWay Stack)

| Приоритет | Платформа | Главная задача | Что генерируем |
|:-:|---|---|---|
| **1** | **Pinterest** (`fitway_best`) | Визуальный SEO-поиск и прямые клики на `fitway.best` | **3-5 разных пинов** на 1 URL + промпты `2:3` в палитре FitWay |
| **2** | **YouTube Shorts** (+ кросс-пост IG Reels / TikTok) | Поисковый охват через видео + перевод в закрепленный комментарий / био | 1 сценарий `9:16` (15-45 сек) + SEO-метаданные + подписи для Reels/TikTok |
| **3** | **X / Twitter** (`@fitway_best`) | Экспертность, научные разборы, миф-бастинг | 1 одиночный пост или тред (4-5 твитов, ссылка в последнем) |
| **Опц.** | **Reddit** (`r/fitness`, `r/loseit`, `r/flexibility`) | Белый посев для Tier-1 переходов и поведенческих сигналов | 1 развернутый ответ без рекламы (только по запросу или под вопрос из треда) |

**Исключено:** Facebook и LinkedIn не генерируются. Не дублируй тексты между платформами копипастом.

## Режимы выбора платформ (отдельно или пакетом)

Скилл **не обязан** каждый раз выдавать все платформы сразу. Выбирай вывод строго по запросу пользователя:

| Запрос пользователя | Что генерируем |
|---|---|
| **Только Pinterest** (*«сгенерируй пины»*, *«пины для...»*, *«только Pinterest»*, *«сделай 3 пина»*) | **Только Блок 1 (Pinterest Pack)**. По умолчанию 3-5 пинов (или точное число, которое попросил пользователь, например 1 или 2). |
| **Только YouTube Shorts** (*«сценарий Shorts»*, *«только Shorts»*, *«видео для YouTube»*) | **Только Блок 2 (YouTube Shorts Pack)** (+ компактные подписи для кросс-поста в Reels/TikTok, если пользователь не попросил строго без них). |
| **Только X / Twitter** (*«тред для X»*, *«пост в Twitter»*, *«только X»*) | **Только Блок 3 (X / Twitter Pack)**. |
| **Только Reddit** (*«ответ для Reddit»*, *«комментарий на Reddit»*) | **Только Блок 4 (Reddit Value-First Draft)**. |
| **Комбинация** (например, *«Pinterest + Shorts»*) | Только указанные платформы. |
| **Полный пакет** (*«SMM пакет»*, *«контент для всех соцсетей»*, *«repurpose for social»*) | Все актуальные блоки: Pinterest + YouTube Shorts (+ Reels/TikTok) + X (+ Reddit, если упомянут). |

Если пользователь прислал просто URL или тему без указания площадки, спроси в 1 строку или по умолчанию выдай **только Pinterest (приоритет №1)**, а в конце предложи догенерировать Shorts / X / Reddit по желанию.

## Входные режимы

Скилл работает в 4 сценариях (если входных данных не хватает, уточни 1 коротким списком; если дан URL/тема/JSON, генерируй сразу):

1. **Repurpose статьи или тренировки (по умолчанию):** пользователь дает URL, slug, текст или JSON из `posts.json` / `workouts.json`.
2. **Продвижение калькулятора (`/tools/*`):** фокус на одном из 5 калькуляторов и смежных статьях.
3. **По теме / ключевому запросу:** подбор подходящей существующей страницы из реестров `existing-posts.md` / `existing-workouts.md` / `internal-links.md`.
4. **Ответ на вопрос Reddit / сообщества:** генерация белого экспертного комментария + опционального пина/шортса на ту же боль.

## Процесс генерации (пошагово)

### Шаг 1 — Сверка URL, уже опубликованных пинов, ключей и фактов
1. **Найди и проверь URL:** сверь целевую ссылку по `existing-posts.md`, `existing-workouts.md` или `internal-links.md`. **Никогда не выдумывай несуществующие URL `fitway.best`.** Если ссылка ведет на статью, подбери 1 релевантный калькулятор `/tools/*` как дополнительный CTA (например, для статьи о дефиците калорий — пин сразу на `/tools/calorie-calculator`).
2. **Сверься с `references/existing-pins.md` (для Pinterest):** проверь, нет ли уже опубликованного пина на этот URL или тему. Если URL уже есть в реестре (например, `/workouts/full-body-strength-workout-compound-barbell-dumbbell` или `/tools/calorie-calculator`), выбери **принципиально другой угол подачи и визуальный макет**, чтобы не плодить дубликаты. Приоритет — непокрытые статьи, `/tools/ideal-weight-calculator`, `/tools/bmi-calculator` и пустая доска `Nutrition & Macro Tracking`.
3. **Проверь ключи GSC:** открой `brain/data/gsc-latest.json` (`low_hanging_fruits` и `top_queries`). Если по теме есть реальные поисковые фразы (позиции 10-30), вшей их в Pin Title и YouTube Shorts Title.
4. **Зафиксируй факты:** выпиши из исходного материала только реальные цифры, упражнения, формулы и PMID исследований. Ничего не выдумывай.

### Шаг 2 — Сборка пакета контента

Все публичные тексты, заголовки и надписи на картинках пишутся **строго на American English** (пояснения пользователю можно давать на русском, если запрос на русском).

#### Блок 1: Pinterest Pack (3-5 уникальных пинов на 1 материал)
Каждый пин должен атаковать **разный поисковый интент** и иметь **свой визуальный формат** (детали в `references/pinterest-seo-guide.md`):
- Пин 1: **Data / Infographic** (таблица, сравнение, формула, схема).
- Пин 2: **Checklist / Step-by-Step Guide** (пошаговый план или 5 правил).
- Пин 3: **Myth vs Science / Problem-Solution** (разбор частой ошибки + доказательный подход).
- Пин 4 (при наличии релевантного `/tools/*`): **Calculator Promo Pin** (прямой оффер на бесплатный расчет на `fitway.best/tools/...`).

Для каждого пина выдай:
- **Target URL (с UTM)** (`https://fitway.best/...?utm_source=pinterest&utm_medium=social&utm_campaign=<topic_pinN>`)
- **Target Board** (одно из 5 точных названий досок из `references/pinterest-seo-guide.md`)
- **Pin Title** (40-100 символов, точный long-tail ключ в начале)
- **Pin Description** (250-500 символов; ключевой запрос в первых **50 символах** до обрезки «More»; естественные предложения без переспама; 0-3 чистых хэштега или без них; четкий CTA)
- **Alt Text** (80-150 символов, описывает визуал + включает ключевик для доступности и SEO)
- **On-Image Text Overlay** (короткий заголовок 4-8 слов + 2-4 кратких буллета/метки для вертикали `2:3`)
- **Visual Direction & Image Prompt (`--ar 2:3`)**: готовый английский промпт для генератора изображений (`1000x1500` / `--ar 2:3`) строго в dark-mode дизайн-коде FitWay (`#1B2B3B`, `#243447`, `#FF8C00`, `#FFFFFF`, `#D1D5DB`) с точным текстом оверлея в кавычках.
- **Queue Export (`scripts/pinterest/queue.json`)**: если пользователь просит подготовить пины в очередь автопостинга (или по умолчанию в режиме Pinterest), добавь готовые JSON-записи со статусом `"pending"` и именем файла `<id>.png` в `scripts/pinterest/queue.json`, чтобы пользователю осталось только положить сгенерированные картинки в `scripts/pinterest/assets/` (проверь валидность командой `node scripts/pinterest/index.js --validate`).

#### Блок 2: YouTube Shorts Pack (+ легкая адаптация для IG Reels и TikTok)
Используй фреймворк из `.agents/skills/social/references/short-form-video.md` и `references/platform-playbooks.md`:
- **YouTube Shorts SEO Title** (до 70 видимых символов, макс. 100; поисковый запрос + конкретная польза/цифра)
- **YouTube Description** (2-3 строки с ключами + ссылка на статью/калькулятор + 3-5 хэштегов)
- **Pinned Comment** (короткий вопрос для вовлечения + прямая ссылка `https://fitway.best/...`)
- **Tags** (5-8 релевантных тегов)
- **Script (15-45 sec, `9:16`)**:
  - `[0-3s] Triple Hook`: `[Visual Hook]` + `[Verbal Hook]` + `[On-Screen Text Overlay]`
  - `[3-35s] Body`: динамичные биты по таймкодам (макс. 2 строки субтитров на экране, 3-5 слов в строке)
  - `[35-45s] CTA`: четкий переход к описанию / закрепленному комментарию
- **Cross-Post Adaptation**:
  - **Instagram Reels (`@fitway.best`)**: подпись до 125 символов до «more» + CTA «Link in bio» + 3-5 хэштегов (официальный лимит IG — макс. 5).
  - **TikTok**: живой разговорный хук-подпись до 150 символов + 3-5 хэштегов.

#### Блок 3: X / Twitter Pack (`@fitway_best`)
Выдай на выбор:
- **Вариант A (Single Insight Post, <= 280 chars)** с 1-2 хэштегами или без них, **или**
- **Вариант B (Educational Thread, 4-5 tweets, каждый <= 280 chars)**:
  - Tweet 1: сильный факт/миф без внешней ссылки (чтобы не резать охват).
  - Tweets 2-4: практический разбор, цифры, ссылка на научный принцип/PMID.
  - Final Tweet: вывод + ссылка `https://fitway.best/...` (1-2 хэштега максимум).

#### Блок 4: Reddit Value-First Draft (генерируй, если запрошен или дана ветка/вопрос)
- Целевой сабреддит (`r/fitness`, `r/loseit`, `r/flexibility`, `r/strength_training`, `r/nutrition`).
- Полностью самостоятельный полезный ответ по правилам сообщества (никакого рекламного тона, 100% польза внутри текста, нативная ссылка на калькулятор или статью с таблицей/PMID только как вспомогательный инструмент).

### Шаг 3 — Валидация перед выдачей (обязательно)

Перед тем как отдать ответ, проверь весь сгенерированный текст по чеклисту:
- [ ] **Пройдена вычитка по `.agents/skills/humanizer/SKILL.md`**: нет *"Not X, but Y"*, *"Let's dive in"*, *"game-changer/crucial/delve/unlock/elevate"*, искусственных финальных однострочников и навязчивых триад.
- [ ] **Ноль длинных и средних тире (`—`, `–`)**: проверены все заголовки, описания, тексты на картинках, субтитры и твиты. Используй `-`, `:` или запятые.
- [ ] **Лимиты платформ соблюдены**: Pinterest Title <= 100, Description <= 500 (ключ в первых 50); YT Shorts Title <= 70 (макс. 100), Hashtags <= 5; IG Hashtags <= 5; X Tweet <= 280.
- [ ] **Дизайн-код FitWay в промптах**: указаны `--ar 2:3`, `#1B2B3B`, `#243447`, `#FF8C00` / `#C25700`, `#FFFFFF`, `#D1D5DB`, никаких белых фонов.
- [ ] **Валидность URL и YMYL**: все ссылки существуют в реестрах FitWay; нет медицинских диагнозов и обещаний экстремального похудения.
