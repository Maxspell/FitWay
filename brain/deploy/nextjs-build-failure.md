# Next.js Production Build Failure: Missing Manifest

**ОШИБКА:**
`Error: ENOENT: no such file { ... } open '.next/prerender-manifest.json'`
`HTTP 502 Bad Gateway` (Nginx)

**КОНТЕКСТ:**
Ошибка возникает при попытке запустить приложение через PM2 (`next start`) после обновления кода, если не был выполнен этап сборки.

**ПРИЧИНА:**
Команда `next start` ожидает наличия скомпилированного билда в папке `.next`. Если файлы были удалены или проект был обновлен через git без запуска билда, Next.js не находит манифест предварительного рендеринга страниц.

**РЕШЕНИЕ:**
Необходимо выполнить полный цикл деплоя:
1. `git pull` — обновление исходников.
2. `npm install` — обновление зависимостей.
3. `npm run build` — генерация папки `.next` (создание манифестов).
4. `pm2 restart [app_name]` — перезапуск процесса.
