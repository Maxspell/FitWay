# Workout Library UI & Catalog Architecture

Документация по интерфейсу и архитектуре библиотеки тренировок FitWay (`/workouts` и `/workouts/page/[page]`).

## Контекст и цели
Страница библиотеки тренировок является ключевым хабом обнаружения контента и важным элементом SEO-стратегии FitWay. Для улучшения взаимодействия с пользователем (UX), единообразия визуального языка платформы и прохождения модерации Google AdSense были реализованы следующие изменения:
1. **Синхронизация фильтров со схемой Strapi**: устранён хардкод категорий, добавлены все доступные типы тренировок.
2. **Перенос вводного текста под пагинацию**: пользователи и мобильные посетители сразу видят каталог доступных программ вместо необходимости долгого скролла мимо описания.
3. **Единый дизайн карточек тренировок (`WorkoutCard`)**: карточки в каталоге приведены к 100% визуальному соответствию карточкам с главной страницы (`FeaturedWorkouts`).

## 1. Унифицированная карточка тренировки (`WorkoutCard.tsx`)

Ранее на главной странице (`FeaturedWorkouts.tsx`) и в каталоге (`WorkoutView.tsx`) использовались две разные разметки карточек, что нарушало консистентность UI и затрудняло поддержку стилей.

Компонент вынесен в отдельный переиспользуемый модуль:
`src/components/workouts/WorkoutCard.tsx`

### Дизайн-система карточки
- **Форма и фон**: `rounded-[2rem] bg-[#243447]/50 backdrop-blur-xl border border-white/5` с интерактивной оранжевой рамкой `hover:border-[#FF8C00]/30` и мягким подъёмом `hover:-translate-y-2`.
- **Glow-эффект**: Неоновое рассеянное свечение `group-hover:via-[#FF8C00]/10 blur-2xl` при наведении курсора.
- **Медиа-контейнер**:
  - Высота `h-64 overflow-hidden` с плавным приближением фото `group-hover:scale-110 duration-700`.
  - Градиентная подложка `from-[#1B2B3B] via-[#1B2B3B]/20 to-transparent`.
  - Оранжевая кнопка `Play` по центру, плавно проявляющаяся и масштабирующаяся на hover.
  - Бейджи в левом верхнем углу: сложность (`workout.difficulty` оранжевым бейджем) и категория (`workout.category` полупрозрачным бейджем `bg-white/10 backdrop-blur-md`).
- **Блок метаданных**:
  - Информационные капсулы `bg-white/5 border border-white/5 group-hover:bg-[#FF8C00]/5`: длительность (`Duration`) и сожжённые калории (`Calories`) с фирменными иконками `Clock` и `Flame`.
- **Футер карточки**:
  - Целевые мышечные группы (`Target` + `workout.targetMuscleGroups`).
  - Интерактивный призыв `Start ->` с анимацией смещения стрелки `ChevronRight`.
- **Анимации появления**: `framer-motion` со ступенчатой задержкой по индексу: `delay: (index % 9) * 0.08`.

## 2. Категории и фильтрация

Схема контент-типа Strapi v5 (`backend/src/api/workout/content-types/workout/schema.json`) определяет следующий перечень категорий:
- `weight-loss` (Weight Loss)
- `muscle-gain` (Muscle Gain)
- `toning` (Toning)
- `flexibility` (Flexibility)
- `strength` (Strength)

В компоненте `WorkoutView.tsx` массив `filters` приведен в полное соответствие схеме:
```typescript
const filters = [
  { id: "all", label: "All Workouts" },
  { id: "weight-loss", label: "Weight Loss" },
  { id: "muscle-gain", label: "Muscle Gain" },
  { id: "toning", label: "Toning" },
  { id: "flexibility", label: "Flexibility" },
  { id: "strength", label: "Strength" },
];
```
Каждый переключатель фильтра сохраняет выбранное состояние (`selectedCategory === filter.id`) и корректно передается в query-параметры URL (`?category=...`), а также поддерживается в компоненте пагинации `Pagination.tsx`.

## 3. Информационная иерархия и SEO-описание

Вводный образовательный блок, необходимый для раскрытия методологии FitWay и устранения замечаний "Thin Content / Low Value Content", ранее располагался над каталогом тренировок и сдвигал сетку вниз.

### Изменения структуры:
1. **Первый экран**: Посетители сразу видят заголовок страницы, общее количество страниц/текущую страницу и интерактивную панель фильтрации по категориям, за которыми немедленно следуют карточки тренировок.
2. **Размещение после пагинации**: Образовательный текст перенесен в блок `mt-16` под компонентом `<Pagination />`.
3. **Расширение карточек категорий**: Добавлены недостающие описания для направлений **Flexibility** и **Strength**:
   - **Weight Loss**: Метаболическое кондиционирование и расход калорий для снижения веса и здоровья сердечно-сосудистой системы.
   - **Muscle Gain**: Силовые тренировки и гипертрофические диапазоны повторений для наращивания сухой мышечной массы.
   - **Toning**: Сбалансированный подход с умеренными весами и высоким числом повторений для рельефа.
   - **Flexibility**: Подвижность суставов, улучшение осанки и эластичность связок для снижения риска травм и ускорения восстановления.
   - **Strength**: Базовые многосуставные движения, нервно-мышечная адаптация и развитие максимальной силы.
4. **Адаптивная сетка категорий**: `grid-cols-1 sm:grid-cols-2 lg:grid-cols-3 gap-6` для гармоничного отображения 5 карточек на любых экранах.
