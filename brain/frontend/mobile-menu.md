# Mobile Menu Implementation

## Обзор
Реализован премиальный мобильный компонент `MobileMenu.tsx` для главной навигации платформы FitWay, полностью соответствующий существующей дизайн-системе.

## Технологии
- **Next.js** (App Router)
- **Tailwind CSS** (Стилизация)
- **Framer Motion** (Комплексные анимации)
- **Lucide React** (Иконки)

## Архитектурные решения
- **Server/Client split**: Компонент использует `"use client"` для работы с хуками React (`useState`, `useEffect`, `useRef`), роутингом (`usePathname`) и анимациями `framer-motion`.
- Интеграция в **Header**: `Header.tsx` содержит одновременно десктопный `Navbar` и мобильный `MobileMenu`. Видимость переключается через Tailwind классы (`hidden md:flex` для десктопа и `md:hidden` для мобилки).

## UX/UI Улучшения
- Плавный выезд панели справа налево и появление заднего фона (backdrop blur) с использованием кастомных transition ease.
- Stagger-эффект для пунктов меню: каждый элемент появляется с небольшой задержкой (0.05s) после родителя.
- **Предотвращение Layout Shift**: при открытии меню `body.overflow` устанавливается в `hidden`, чтобы запретить скролл, а также добавляется компенсация `paddingRight` равная ширине системного скроллбара, чтобы интерфейс "не прыгал".
- Интегрирован блок Call-To-Action (CTA) "Start Your Fitness Journey" и ссылки на социальные сети.

## Доступность (A11y)
- Автоматическое закрытие по нажатию клавиши `Escape` или клику по заднему фону.
- Использование ARIA-атрибутов (`aria-expanded`, `aria-controls`, `aria-label`, `aria-hidden` для декоративного бекдропа).
- Выделение фокуса при клавиатурной навигации через `focus-visible`.
