# Table of Contents Component

## Описание
Премиальный компонент `TableOfContents` для страниц блога FitWay. Реализован с учетом дизайн-системы, поддерживает Scroll Spy (отслеживание текущего H2), имеет прогресс-бар чтения и плавные CSS анимации. Весь сайдбар, содержащий компонент, сделан "липким" (`sticky`).

## Особенности реализации
1. **Premium UI**: Эффекты glassmorphism (`backdrop-blur-md bg-[#1B2B3B]/90`), тонкие границы, анимированный индикатор активного раздела в виде расширяющейся линии с оранжевым свечением.
2. **Scroll Spy & Performance**: 
   - Используется `requestAnimationFrame` в пассивном `scroll` слушателе вместо `IntersectionObserver` для более точного контроля и учета длинных секций, особенно при прокрутке вверх.
   - Избежание перерисовок компонентов за счет использования функционального обновления состояния в `setActiveId`.
3. **SEO & SSR**: 
   - Заголовки (H2/H3) получают стабильные ID-якоря прямо при серверном рендеринге (SSR) через модификацию `components` в `ReactMarkdown` с помощью утилиты `slugify`. Это предотвращает смещение контента (CLS).
   - Компонент автоматически скрывается, если на странице меньше 2 заголовков.
4. **Layout**:
   - Весь контейнер сайдбара (`col-span-4 space-y-6 sticky top-24 h-fit`) фиксируется при скролле, а не только сам блок TOC.

## Структура
- Компонент: `frontend/src/components/BlogPost/TableOfContents.tsx` (Client Component)
- Интеграция: `frontend/src/app/blog/[slug]/page.tsx`
- Утилита для ID: `frontend/src/utils/slugify.ts`
