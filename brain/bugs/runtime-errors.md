# Strapi Runtime Errors

## Port 1337 already in use

**ОШИБКА:**
При попытке запуска Strapi (`npm run start` или `npm run develop`) возникает ошибка:
```text
error: The port 1337 is already used by another application.
info: Shutting down Strapi
```

**ПРИЧИНА:**
Порт 1337 (стандартный порт Strapi) уже занят другим процессом. Это часто случается на VPS, если:
1. Strapi уже работает в фоне (например, запущен через PM2, Docker или tmux/screen).
2. Процесс Node.js предыдущего запуска "завис" и не завершился корректно при остановке.
3. Какое-то другое приложение использует этот порт.

**РЕШЕНИЕ:**
Необходимо найти и завершить процесс, который занимает порт 1337.

**Шаг 1: Найти PID процесса, слушающего порт 1337**
```bash
lsof -i :1337
# или
netstat -tulpn | grep 1337
```

**Шаг 2: Завершить процесс (замените <PID> на полученный номер)**
```bash
kill -9 <PID>
```

**Если вы используете PM2:**
Возможно, вы пытаетесь запустить проект вручную, тогда как он уже крутится в PM2. Проверьте список запущенных процессов:
```bash
pm2 status
```
И если нужно, перезапустите сервис через PM2 или остановите его для ручного запуска:
```bash
pm2 restart strapi
# или
pm2 stop strapi
```
