# FitWay — AI Project Context

## Project Overview

FitWay is a fitness and healthy lifestyle platform built with React (frontend) and Strapi (backend CMS).

The website provides articles, workout programs, nutrition advice, health recommendations, motivational content, fitness tools, and optional e-commerce functionality.

Main goal:
Help users improve fitness, nutrition, health, and productivity through accessible educational content and practical tools.

---

# Tech Stack

## Frontend
- React
- React Router
- Axios
- TailwindCSS / SCSS
- Vite (optional)

## Backend
- Strapi CMS
- REST API / GraphQL
- JWT Authentication

## Database
- PostgreSQL / MySQL / SQLite
